# 首次使用

本文假定 Amane 已经安装并成功启动。

## 1. 登录

浏览器打开 Amane：

- Docker：`http://<主机地址>:8016`
- 桌面版：`http://127.0.0.1:18000`

输入 API Token。Token 的获取方式见 [安装与升级](installation.md)。

## 2. 提交第一次刮削

进入“运行 → 任务”，点击“提交任务”：

1. 类型选择“刮削”。
2. 填写番号，例如 `MIDV-123`。
3. 内容类型可以留空，由番号推断。
4. 提交任务。

任务完成后，在“浏览 → 片库”打开影片，可查看：

- 多来源合并后的标题、演员、剧情、发行日期等字段
- 每个字段的来源
- 海报、封面与剧照
- 各站点的原始快照

## 3. 配置本地媒体库

需要整理本地文件时，进入“管理 → 媒体库”添加目录。

关键设置：

- 媒体目录必须是 Amane 可访问的路径
- 根据需要开启递归扫描
- 设置文件扩展名、最小文件大小和黑名单
- 选择自动化级别
- 配置路径模板、NFO、图片和字幕的写出规则

扫描只登记文件；整理、移动或改名由“整理”任务执行。

## 4. 接入 Emby / Jellyfin

推荐由 Amane 写 NFO 与图片，Emby / Jellyfin 只读取，不要同时让媒体服务器保存 NFO。

需要播放 STRM 或使用 302 网关时，再在设置中配置 STRM 与播放代理。

## 5. 自动获得新内容

有三种常用方式：

- **RSS / Atom 订阅**：自动发现并提交新番号
- **定时任务**：定时扫描、刮削或重新刮削
- **文件监控**：本地媒体库出现新文件后自动登记与刮削
